# Interview Tasks

A personal collection of technical tasks and take-home exercises encountered
while interviewing across the job market.

## Layout

Work is grouped by company, and each task lives in its own folder with its own
README, dependencies, and data.

```
<company>/
  <task-name>/
    README.md
    ...
```

## Adding a task

1. Create (or reuse) a folder for the company.
2. Inside it, add a folder for the task with a short, descriptive name.
3. Give that folder a `README.md` covering purpose, how it works, requirements,
   and how to run it.
4. Keep dependencies and data local to the task folder.
